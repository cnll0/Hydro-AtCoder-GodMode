🚀 Hydro-AtCoder-GodMode 一键安装引导

无需科学上网，直接在本地完成 Tampermonkey 扩展与抓题脚本安装

⚠️ 浏览器安全限制： 篡改猴无法从 file:// 本地文件直接安装脚本（双击 HTML 打开只会看到源码或空白页）。
正确姿势： 先双击 start.bat 启动本地服务，再把浏览器地址栏改成 http://localhost:27122/install.html。这样点击脚本链接会直接唤起篡改猴安装框。

✅ 推荐流程（一次配置，以后免装）

  1. 双击 start.bat 启动本地服务（窗口别关）。
  2. 浏览器打开 http://localhost:27122/install.html。
  3. 先点「篡改猴」按钮装扩展；再点两个脚本链接，篡改猴弹出安装框 → 点「安装」。
  4. 回到可达信奥 / AtCoder 题目页，刷新后即可看到抓题按钮。

安装抓题脚本（Tampermonkey 用户脚本）

Tampermonkey 安装完成后，选择以下任一方式添加脚本：

方式 A：一键复制 → 粘贴到 Tampermonkey（最稳妥，推荐）

  1. 点击下面的 📋 复制脚本内容 按钮，脚本代码会自动复制到剪贴板。
  2. 打开浏览器 Tampermonkey 扩展页面，点击“添加新脚本”。
  3. 删除编辑器里的默认代码，把复制的内容全部粘贴进去。
  4. 按 Ctrl+S 保存脚本。

方式 A（推荐）：通过本地服务一键安装

确认地址栏是 http://localhost:27122/install.html（不是 file://），然后直接点下面两个链接，篡改猴会弹出安装框：

如果地址栏是 file://，这些链接只会显示源码——请先双击 start.bat，再用上面的 localhost 地址打开本页。
